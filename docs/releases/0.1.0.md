# AdPilot 0.1.0 — Initial development preview

- **Prepared:** 2026-10-20 (Asia/Tehran)
- **Release type:** Installable development preview for local/staging evaluation
- **Source revision:** `a5a3775b3b9c54169cdfa444bb3f73971c06dde6`, with release documentation additions

AdPilot 0.1.0 packages the current self-hosted WordPress advertising implementation. It includes working publisher and advertiser interfaces, compact inventory, native creative moderation, campaign eligibility, fixed-price quotes, transactional holds, and progressive rendering. The complete 54-package product and independent production release certification remain unfinished.

## Included

- **Publisher console and advertiser portal:** Inventory, campaigns, native creative review, basic scoped reports, settings, diagnostics, organization selection, and the quote/hold/order flow.
- **Inventory and Layout Studio:** Zones, responsive grid containers, stable logical slot identities, paginated search, draft validation, and immutable layout publication. The compiler supports more than 500 logical slots; the Studio uses a bounded schematic rather than loading a live ad for every configured slot.
- **Organizations and permissions:** Publisher capability checks, live organization membership, owner/manager/analyst/billing roles, organization verification/suspension, and protected member role/revocation operations.
- **Native creative review:** Text content and validated destinations, immutable successor versions and content digests, explicit submission, and reasoned exact-version moderation.
- **Campaign eligibility:** Separate approval, financial, and delivery gates; approved-policy complimentary allocations; paid-allocation application logic; pause, resume, and emergency-stop actions.
- **Pricing and reservations:** Exact integer-string money, immutable fixed-window quotes, expiring idempotent exclusive holds, advertising orders, and settlement application logic for duplicate or late synthetic captures.
- **WordPress rendering:** Shared PHP helpers, shortcodes, four dynamic block registrations, nonbillable editor previews, and a lightweight runtime that requests current decisions near the viewport.
- **Operations and documentation:** Site-scoped InnoDB storage, migration checksum/downgrade guards, audit/local outbox processing, CLI diagnostics, consent-gated nonbillable measurement, a comprehensive README, and PHP/Node build commands.

## Requirements

| Component | Requirement |
| --- | --- |
| WordPress | Declared minimum 6.7; the complete compatibility matrix remains uncertified |
| PHP | 8.2 or newer, with WordPress's usual requirements and `mbstring` |
| Database | WordPress MySQL/MariaDB storage with InnoDB for AdPilot tables |
| Browser | JavaScript and modern browser APIs; use HTTPS for deployed interfaces |
| WooCommerce | Optional; installation alone does not enable checkout |
| Activation | Individual site activation; network-wide provisioning is unavailable |

The installed plugin uses WordPress React and prebuilt assets. Python, Composer, Node.js, and npm are not runtime requirements. Node/npm and PHP ZipArchive are build/packaging tools.

## Install or evaluate

1. Back up an existing site's database and files before replacing an earlier preview. Use a disposable/staging site to evaluate this build.
2. Upload `adpilot-0.1.0.zip` through **Plugins → Add New → Upload Plugin** and activate it on the individual WordPress site.
3. Open **AdPilot → Settings** to inspect storage readiness and feature availability.
4. Create a zone/container, publish a layout, and insert a published placement through an AdPilot block, shortcode, or PHP helper.
5. Add `[adpilot_portal]` to a page, create/verify an advertiser organization, submit/review a native creative, and create a campaign. Complimentary delivery additionally requires the publisher's actual manual-allocation policy and an available interval.

No sample site, database, credentials, or campaigns are bundled. Follow the first-campaign walkthrough in `README.md` for the separate organization, creative, entitlement, and schedule steps.

Deactivation stops the plugin's maintenance schedule and retains business data. Uninstall also preserves advertising records, options, and role/capability state; deleting the plugin files is not a data purge. Schema changes still require a reviewed migration and recovery procedure.

## Defaults and known limitations

- **Paid checkout remains unavailable by default.** The optional WooCommerce CRUD/HPOS adapter is present, but real gateway/tax verification, full HPOS compatibility testing, reversals, refunds, legal invoices, and reconciliation/remedy workflows are incomplete. Synthetic settlement tests are not gateway certification, and payment never approves a creative.
- **Only native text creatives are available.** Private raster quarantine/uploads, video, advertiser HTML, and advertiser JavaScript are unavailable.
- **Team invitations and complete ownership transfer are unfinished.** Organization creation gives the current WordPress user an owner membership; it does not provision an arbitrary other user's membership.
- **Layout editing is conservative.** Published geometry is frozen. Full sold-inventory impact migration, undo/redo, and controlled rollback are incomplete. Repeater/showcase registrations currently resolve through the shared renderer; complete query-loop interval and curated showcase behavior is unfinished.
- **Analytics collection starts disabled.** Enabling it requires an actual policy reference, finite retention, a trusted purpose-specific consent adapter, and permitted production context. Browser render claims and clicks are nonbillable. Complete privacy export/erasure, qualified analytics, advanced exports, attribution, and financial aggregates remain outstanding.
- **Some campaign, targeting, notification, and provider workflows are incomplete.** Stop controls govern new decisions/claims; continuous removal of content already painted into a visitor's page is not a completed propagation feature.
- **R2–R4 subsystems are unavailable:** heatmaps, metered CPC/CPM billing, masked replay, federation, and the later provider platform. Outbound webhook endpoints are not registered.
- **Compatibility and release acceptance remain limited.** Complete minimum-version, theme, browser, multisite, accessibility, security/privacy, recovery, and commercial certification are outstanding. See `docs/development/IMPLEMENTATION.md` for the package ledger.

Manual complimentary allocation, advertiser organization signup, and measurement are disabled by default. A configured slot or published placeholder is not an impression or a charge.
